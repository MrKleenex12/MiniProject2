# Reflection: homalg-project_toricvarieties_project

ToricVarieties_project is a set of GAP packages for algebraic geometry, mostly written by Martin Bies. Its timeline is irregular with 5 gaps of at least three months, made up of big bursts of work followed by long quiet periods.

The longest gap was 23 months, from January 2023 to November 2024, and it was hard to interpret from commits alone. The last commits before it look like normal cleanup, such as "Remove old find_connected_components method." The real answer, though, is in PR #206. When a GAP maintainer asked if the package was still maintained, Martin Bies replied that "all of the toric varieties functionality in this package is now available through OSCAR," a newer system. An open segfault in issue #205 from July 2023 was also never fixed.

The project did not recover. The 7 commits after the gap only wind it down: a GAP compatibility fix by Max Horn, a maintainer list update, and README changes before it was withdrawn from GAP. No new people joined. The project is Inactive, with its last commit in January 2025. This means the gap was not a pause but the project being replaced.
