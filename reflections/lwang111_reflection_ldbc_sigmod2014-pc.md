# Reflection: ldbc_sigmod2014-pc

This project is a solution to the SIGMOD 2014 Programming Contest written with GraphBLAS. It is research code with a clear end point, not a tool meant to be maintained forever. Its timeline is declining with 3 gaps of at least three months, and most of the work happened in 2020 and early 2021.

The longest gap was 33 months, from August 2022 to April 2025, and it was easy to interpret. The last commits before it are "Add LICENSE and NOTICE files" and "Add DOI." Adding a DOI registers the code so it can be cited in a paper, which is a strong sign the authors were done. The last issues, #43 and #44 from early 2021, are ideas that were never picked up.

The project did not recover. There is only one commit after the gap, "Fix missing import," by original contributor Márton Elekes in May 2025. Under the 6-month rule it counts as Active, but that is misleading. One small fix three years later is maintenance, not a comeback. This means the long gap is just what a finished research project looks like.
