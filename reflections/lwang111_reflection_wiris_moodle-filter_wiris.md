# Reflection: wiris_moodle-filter_wiris

This project is the MathType plugin for Moodle, an online learning platform. It is maintained by WIRIS, a company, rather than volunteers or researchers. Its timeline is U-shaped, but it has 0 gaps of at least three months, making it the only project in my set that has always been active. I recorded its gap reason as "N/A active Project."

The longest pause was only 2 months, August and September 2022, and nothing about it looks unusual. The commits before it are normal fixes and a 7.30.0 release, and PR #110 was even merged on September 12 during the quiet months. A two-month break over late summer for a company team is most likely vacation and release timing.

Work picked back up in October 2022 with "fix: Flaky tests for Moodle 4.1" and the 8.0.0 release. The same team continued on both sides, and new developers like Ubaldo Santos joined later. The project is Active, with recent commits adding tests for new Moodle versions and publishing 8.11.1. This means the activity is steady, scheduled work tied to Moodle's releases, which is why it never had a real gap.
