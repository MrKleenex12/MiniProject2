# Reflection: asgr_profound

ProFound is an astronomy image tool that is almost entirely written by one person, Aaron Robotham. He made 81 of the 83 commits after the longest gap. The project has 3 gaps of at least three months and is declining overall, which is what you would expect from one researcher working on it around his other work.

The longest gap ran 6 months, from March to August 2024, and it was easy to interpret. The last commit before it finished a feature, "profoundProFound will now load a Rfits_pointer object," and no issues or pull requests were left waiting. Nobody was asking for anything, so there was no reason to keep committing.

The recovery came from his own research. After the gap he added new photometry options, then wrote "Will need this version for the Workshop" and fixed a "Weird corner case for WAVES," a galaxy survey. The same person brought it back. The project is still Active, with recent commits in 2026 that are mostly README and dependency upkeep. This means ProFound is not abandoned. It just moves at the pace of one maintainer's research.
